The `file` sink can now write [Apache Parquet](https://parquet.apache.org/) files. Set `batch_encoding.codec` to `parquet` to have events batched together and encoded as columnar Parquet files instead of the standard per-event, framing-based encoding. A new `batch` option controls how events are grouped into batches when `batch_encoding` is set. Because columnar files cannot be appended to, each batch is written to a distinct file, with a time-ordered UUID (v7) inserted into the rendered `path` before the file extension.
